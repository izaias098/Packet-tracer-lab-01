# Packet Tracer Lab 01

## Objetivo
Criar uma rede local utilizando um roteador Cisco 2911, um switch e três computadores.

## Topologia
- 1 Roteador Cisco 2911
- 1 Switch Cisco 2960
- 3 PCs

## Configuração
- Rede: 192.168.1.0/24
- Gateway: 192.168.1.1

## Testes realizados
- Comunicação entre os PCs
- Ping para o gateway
- Rede funcionando corretamente
